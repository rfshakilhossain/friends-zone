# Friends Zone

Friends Zone is a Flutter social app powered by Supabase.

1. Run `supabase_schema.sql` in the Supabase SQL Editor.
2. Enable Email/Password under Supabase Authentication.
3. Add GitHub repository secrets `FZ_SUPABASE_URL` and `FZ_SUPABASE_PUBLISHABLE_KEY`.
4. Run the Android workflow.

See `README_SUPABASE_SETUP.md` for the full setup.
